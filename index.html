Sobre mí

Soy estudiante de Desarrollo Web y me especializo en construir páginas claras, organizadas y fáciles de usar. Me interesa el código limpio, el diseño con alto contraste y el cumplimiento de criterios de accesibilidad para que cualquier persona pueda navegar sin barreras.

Más información profesional

Estudio estructura HTML5, CSS (Flexbox, Grid y modelo de caja) y principios de accesibilidad web. Busco crear interfaces comprensibles, con encabezados ordenados, textos alternativos y formularios correctamente etiquetados.

Mi objetivo es seguir fortaleciendo frontend accesible y aplicar estas prácticas en proyectos académicos y profesionales.

Intereses y enfoque de aprendizaje

Me gusta combinar diseño visual sobrio con semántica correcta: landmarks, enlaces descriptivos y componentes nativos como progress, details y summary.

Habilidades

HTML5 semántico

Estructura con header, nav, main, section y footer para una lectura clara por personas y tecnologías de asistencia.

CSS y diseño visual

Uso de Flexbox, CSS Grid, modelo de caja y paletas de alto contraste para una presentación profesional y legible.

Accesibilidad web

Enlace de salto, textos alternativos, etiquetas en formularios, foco visible y contraste suficiente según criterios W3C.

Organización de proyectos

Separación de contenido y estilo, nombres claros de archivos y páginas listas para validación HTML y revisión WAVE.
